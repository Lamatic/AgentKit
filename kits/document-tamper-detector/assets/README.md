# Test Assets

This directory is meant to hold sample documents for demonstrating and testing the Document Tamper Detector.

## Recommended Test Set

For the challenge submission, prepare the following test documents:

### Genuine Documents (2–3)
| File | Description | Expected Risk Score |
|---|---|---|
| `genuine-invoice.pdf` | A real invoice generated by standard accounting software (e.g. QuickBooks, Wave) | 0–20 |
| `genuine-payslip.pdf` | A payslip generated by HR software — uniform fonts, consistent metadata | 0–15 |
| `genuine-id-scan.jpg` | A clean smartphone scan of an ID — EXIF present, no compression anomalies | 5–25 |

### Tampered Documents (2–3)
| File | Description | Expected Risk Score | Expected Flags |
|---|---|---|---|
| `tampered-invoice-total.pdf` | Invoice where the total amount was edited in Photoshop — metadata will show image editor as producer | 55–80 | metadata (software), font_spacing (total amount) |
| `tampered-payslip-salary.jpg` | Payslip photo where the salary figure was copy-pasted from another document — visible JPEG structure anomaly | 60–85 | ela (structure), vlm (visual) |
| `tampered-date-modified.pdf` | Document where the date was modified — creation/modification date mismatch in PDF metadata | 40–65 | metadata (date mismatch) |

## How to Create Test Documents

### Creating a Tampered JPEG (for ELA testing)
1. Take any document photo (JPEG)
2. Open in GIMP or Photoshop
3. Copy-paste a different number/name over existing text
4. Export as JPEG at 85% quality
5. This will create compression structure anomalies detectable by Signal 3 (ELA)

### Creating a Tampered PDF (for metadata testing)
1. Take any legitimate PDF
2. Open in Adobe Acrobat or a PDF editor
3. Edit a figure or name
4. Save — the modification date will now differ from the creation date

## Notes
- Do NOT commit real personal documents or PII
- Use synthetic/generated documents for testing whenever possible
- The detector is a triage tool — expect some false positives on complex documents
