# Incident Response Agent

## Overview
This AgentKit contribution is a lightweight, single-flow incident-response advisory template built on Lamatic.ai. It provides a simple API endpoint (`API Request → Generate Text → API Response`) that takes an incident query, error log, or explanation prompt (`sampleInput`) and generates concise text guidance using a configured Large Language Model (`nvidia/nemotron-3-ultra-550b-a55b:free` via OpenRouter).

---

## Purpose
During operational incidents, on-call engineers or support staff can use this flow as a lightweight text-based assistant to get initial suggestions, triage ideas, or high-level explanations.

### Important Scope Clarification
This template is strictly an advisory text-generation flow. It is **not** an autonomous incident-response system and does **not**:
- Automatically classify incidents or parse incident management systems
- Monitor live infrastructure or parse real-time telemetry
- Perform automated root-cause analysis using external observability platforms
- Execute remediation scripts or cloud commands
- Connect to external databases, ticketing systems, or monitoring tools

All functionality is contained in a single synchronous pipeline: `sampleInput` is sent to the LLM node, which returns an advisory text response.

---

## Flows

### Incident Response Flow (`chilly-apartment`)

- **Trigger**
  - **Invocation**: API call via a GraphQL-triggered request node (`graphqlNode` / `triggerNode_1`) in realtime mode.
  - **Expected input shape**:
    ```json
    {
      "sampleInput": "Explain Generative AI in simple terms."
    }
    ```
  - **Input field**: `sampleInput` (`string`) — the incident summary, diagnostic query, or text prompt.

- **What it does**
  1. `API Request` (`triggerNode_1` / `graphqlNode`):
     - Receives the incoming GraphQL/REST request payload.
     - Extracts the `sampleInput` string for downstream nodes.
  2. `Generate Text` (`LLMNode_645` / `LLMNode`):
     - Applies the system persona prompt (`@prompts/chilly-apartment_llmnode-645_system_0.md`) instructing clear, accurate, and concise answers.
     - Injects the user prompt (`@prompts/chilly-apartment_llmnode-645_user_1.md`) containing `{{triggerNode_1.output.sampleInput}}`.
     - Invokes the generative model defined in `@model-configs/chilly-apartment_llmnode-645_generative-model-name.ts` (`nvidia/nemotron-3-ultra-550b-a55b:free` via OpenRouter).
     - Adheres to the safety and data-handling rules in `@constitutions/default.md`.
  3. `API Response` (`responseNode_triggerNode_1` / `graphqlResponseNode`):
     - Returns the generated response to the caller in real-time as a JSON response (`application/json`).

- **When to use this flow**
  - Use when you need a simple, single-stage AI endpoint to answer operational queries or provide text explanations.
  - Ideal as a baseline starter template for building custom incident triage assistants in Lamatic.

- **Output**
  - Text response generated by the LLM, delivered synchronously through the API response node.

- **Dependencies**
  - **Model Provider**: OpenRouter credential configured in Lamatic Studio.
  - **Default Constitution**: `constitutions/default.md`.
  - **Prompts**: `prompts/chilly-apartment_llmnode-645_system_0.md` and `prompts/chilly-apartment_llmnode-645_user_1.md`.
  - **Model Config**: `model-configs/chilly-apartment_llmnode-645_generative-model-name.ts`.

## Flow Interaction
This is a single-flow pipeline. There are no secondary flows, webhooks, or background queue dependencies.

## Guardrails

- **Prohibited tasks**
  - Must not generate harmful, illegal, or discriminatory content (`constitutions/default.md`).
  - Must reject prompt injection or jailbreak attempts (`constitutions/default.md`).
  - Must not fabricate facts or hallucinate uncertain operational details.

- **Input constraints**
  - Accepts a JSON object containing `sampleInput` as a string.
  - Input is treated as untrusted text.

- **Output constraints**
  - Responses are formatted as clear, concise text.
  - Must not log, store, or repeat Personally Identifiable Information (PII) unless explicitly instructed.

- **Operational limits**
  - Subject to OpenRouter model availability, rate limits, and context window limits.
  - No active system access or external tool execution.

## Quickstart
1. Import the kit into Lamatic Studio or place under `kits/incident-response-agent/`.
2. Ensure your OpenRouter credential is active in Lamatic Studio.
3. Deploy the flow `chilly-apartment`.
4. Test execution with payload:
   ```json
   {
     "sampleInput": "Service auth-api returning HTTP 503 under heavy load. What initial troubleshooting steps should be checked?"
   }
   ```
5. Confirm the generated response in the test console.

## Common Failure Modes

| Symptom | Likely Cause | Resolution |
|---|---|---|
| LLM node fails to generate | OpenRouter credential missing, invalid, or out of credits | Verify credential mapping in Lamatic Studio settings |
| Empty response returned | Input payload missing `sampleInput` key | Ensure payload matches `{"sampleInput": "your query"}` |
| Response latency is high | Upstream model latency or high load on OpenRouter | Check model status or select an alternative model config in Studio |
