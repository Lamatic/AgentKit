# API Security Fuzzer Kit

This kit provides an AI agent that takes an OpenAPI specification and acts as an automated security engineer, analyzing the API contracts to generate malicious, edge-case, and malformed JSON test payloads for every endpoint.

## Getting Started

1. Set up the environment variables in `apps/.env.local`.
2. Run `npm install` inside the `apps/` directory.
3. Run `npm run dev` to start the Next.js development server.
