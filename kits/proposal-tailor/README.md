# Freelance Proposal Tailor Kit

A Next.js web application powered by Lamatic.ai that generates tailored, high-converting freelance proposals.

## Setup Instructions

1. Configure your environment variables in `apps/.env.local`:
   - `LAMATIC_API_KEY`
   - `LAMATIC_PROJECT_ID`
   - `LAMATIC_API_URL`
   - `LAMATIC_WORKFLOW_ID`

2. Run the development server:
   ```bash
   cd apps
   npm install
   npm run dev
   ```
